# Sukoontalk App Hub

Need to build a  landing page for Sukoontalk to download app from the playstore.

Having below pages/ URLs:
1. Landing page (theme to be kept as Sukoontalk). Majorly highlighting Android playstore download section. 
General FAQs regarding Sukoontalk.
2. Terms & Conditions (content PDF Attached)
3. Privacy Policy (content PDF Attached)
4. User account deletion page (Name, phone, email, submit cta). Account will be deleted in 3 business days.

Remember to not use content specifically having Islam/ Muslim or such core religious word which can be identified by a crawling bot. Need to keep the theme (graphics tilted to Islam) but no readable word piting to it. We have vet the T&Cs already for it.

You can take reference of homepage of project - sukoontalk-connect for design system. Use same design system for the landing pages and other urls share above to be created.
